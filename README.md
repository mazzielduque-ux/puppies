# Puppies

Este proyecto es una página web hecha como pre entrega de desarrollo front-end.

## Descripción

El sitio está pensado para mostrar información y servicios relacionados con el cuidado de mascotas, especialmente perros.

## Tecnologías usadas

- HTML
- CSS
- Flexbox y Grid
- Google Fonts
- Formspree

## Funciones del sitio

- Navegación interna entre secciones
- Servicios en formato de cards
- Reseñas de usuarios
- Formulario de contacto funcional
- Diseño responsivo
